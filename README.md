# Учёт закупок

Простой сайт для учёта закупок и возвратов в тенге: итоги, круговая диаграмма по категориям, график по месяцам и дням, выгрузка в Excel (CSV), резервная копия в JSON.

- **Открыть сайт:** https://nurlan-rashitovich.github.io/zakupki/
- `index.html` — офлайн-версия: один файл без библиотек, данные хранятся в браузере (`localStorage`). Можно скачать и открыть двойным щелчком.
- `zakupki-online.html` — версия с общей базой для нескольких людей; работает только как артефакт на claude.ai.
- `PRD.md` — описание продукта и требований.
