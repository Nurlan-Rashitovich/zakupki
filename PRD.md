# PRD: Учёт закупок

| | |
|---|---|
| **Продукт** | Веб-сайт для учёта закупок и возвратов |
| **Статус** | Версия 2: общая база (`zakupki-online.html`, опубликован на claude.ai). Версия 1 — офлайн (`index.html`) |
| **Дата** | 13.11.2026 |
| **Валюта** | Тенге (₸) |

---

## 1. Задача

Сотруднику нужен простой инструмент, чтобы:
- записывать, что он **купил**;
- записывать, что он **вернул**;
- видеть, **на что потрачены деньги**, в виде графиков.

Главное требование к оформлению — **минимализм**: ничего лишнего, всё видно на одном экране.

## 2. Пользователь

**Сотрудник, который отвечает за закупки.** Он вносит записи вручную после каждой покупки или возврата и время от времени смотрит итоги и графики за месяц или за всё время.

Технических знаний от пользователя не требуется: сайт открывается двойным щелчком по файлу.

## 3. Цели и критерии успеха

| Цель | Критерий |
|---|---|
| Быстро внести запись | Одна строка формы, добавление в 5 полей + одна кнопка |
| Понять, сколько потрачено | Итог (покупки − возвраты) виден сразу вверху страницы |
| Понять, на что потрачено | Круговая диаграмма по категориям с % и суммами |
| Видеть динамику | Столбчатый график по месяцам / по дням |
| Не потерять данные | Есть резервная копия и восстановление из файла |
| Передать данные бухгалтерии | Выгрузка в CSV, который открывается в Excel |

## 4. Функциональные требования

### 4.1. Добавление записи
Форма «Новая запись» с полями:

| Поле | Тип | Обязательное | Примечание |
|---|---|---|---|
| Тип | Переключатель «Покупка / Возврат» | да | По умолчанию «Покупка» |
| Что | Текст | да | Название товара или услуги |
| Категория | Текст с подсказками | да | Список подсказок: стандартные категории + все ранее использованные |
| Дата | Дата | да | По умолчанию — сегодня |
| Сумма | Число ≥ 0, шаг 0.01 | да | Всегда вводится положительной; знак определяется типом |

Стандартные категории: Канцелярия, Хозтовары, Продукты, Техника, Мебель, Транспорт, Прочее.

После добавления поля «Что» и «Сумма» очищаются, курсор возвращается в поле «Что» — чтобы быстро вносить несколько записей подряд. Тип, категория и дата сохраняются.

### 4.2. Итоги (три карточки сверху)
- **Куплено** — сумма всех покупок за выбранный период.
- **Возвращено** — сумма всех возвратов (выделена зелёным).
- **Итого потрачено** — куплено минус возвращено.

### 4.3. Выбор периода
- Поле выбора месяца в шапке.
- Кнопка «Всё время» сбрасывает фильтр (подсвечена, когда активна).
- Период влияет на итоги, круговую диаграмму, таблицу и выгрузку CSV.

### 4.4. График «На что потрачено» (круговая диаграмма)
- Чистые расходы по категориям: покупки минус возвраты в этой категории.
- Категории с нулевым или отрицательным итогом не показываются.
- Если категорий больше 7 — первые 6 показываются отдельно, остальные объединяются в «Остальное» (серый цвет).
- В центре — общая сумма.
- Легенда: цвет, категория, доля в %, сумма.
- При наведении на сектор — подсказка с категорией и суммой.
- Если данных нет — пустое кольцо с надписью «нет данных».

### 4.5. Столбчатый график
- **Период «Всё время»:** чистые расходы по месяцам за последние 12 месяцев.
- **Выбран месяц:** чистые расходы по дням этого месяца (подписи каждые 5 дней).
- Над графиком — подпись максимального значения.
- При наведении на столбец — подсказка с суммой.

### 4.6. Таблица записей
- Колонки: Дата, Что, Категория, Тип, Сумма, кнопка удаления.
- Сортировка: сначала новые.
- Возвраты помечены зелёным тегом «возврат» и суммой со знаком «−».
- Удаление — по кнопке ✕ с подтверждением.
- Пустое состояние: «Пока нет записей».

### 4.7. Выгрузка и резервное копирование
- **Excel (CSV)** — выгрузка записей выбранного периода. Разделитель `;`, кодировка UTF-8 с BOM (корректно открывается в Excel на русском). Возвраты — с отрицательной суммой. Имя файла: `zakupki.csv` или `zakupki-ГГГГ-ММ.csv`.
- **Резервная копия** — все записи в JSON-файл `zakupki-backup-ГГГГ-ММ-ДД.json`.
- **Восстановить** — загрузка JSON-файла с подтверждением замены текущих данных; при ошибке — сообщение «Не удалось прочитать файл».

## 5. Дизайн

- **Минимализм:** нейтральная палитра (тёплый серый), белые карточки с тонкой рамкой и скруглением, без лишних декоративных элементов.
- Один цвет-акцент для графиков, зелёный — для возвратов, красный — при наведении на удаление.
- Цифры выровнены моноширинно (табличные цифры).
- **Тёмная тема** включается автоматически по настройке системы.
- **Мобильная версия** (ширина < 760px): карточки и графики идут в одну колонку, форма — в две, колонка «Категория» в таблице скрыта.
- Язык интерфейса — русский.

## 6. Технические решения

| Решение | Обоснование |
|---|---|
| Один файл `index.html` (HTML + CSS + JS) | Не требует установки, сервера и интернета |
| Без внешних библиотек | Графики нарисованы вручную на SVG — работают офлайн |
| Хранение в `localStorage` браузера (ключ `purchases.v1`) | Простейший вариант без сервера |

### Модель данных
Каждая запись:
```json
{
  "id": "уникальная строка",
  "type": "buy | ret",
  "name": "Ноутбук",
  "cat": "Техника",
  "date": "2026-11-13",
  "amount": 350000
}
```
`amount` всегда положительный; для расчётов возврат вычитается.

## 7. Ограничения текущей версии

- **Данные живут только в одном браузере на одном компьютере.** С другого устройства или из другого браузера записей не видно.
- Очистка данных браузера удаляет все записи — защита только через ручную резервную копию.
- Нет редактирования записи (только удаление и повторное добавление).
- Нет связи возврата с конкретной покупкой.
- Нет учёта количества и цены за единицу — только общая сумма.
- Нет пользователей, ролей и истории изменений.
- Валюта задаётся в коде (константа `CURRENCY`), без настройки в интерфейсе.

## 8a. Версия 2 — общая база (реализовано 13.11.2026)

Сайт опубликован как приватный Claude-артефакт: https://claude.ai/artifact/WaBBQPKhZ1kWRrKHNdPmAz

- **Хранение:** общая база артефакта, коллекция `purchases`, одна запись = один документ (поля из модели данных + `createdAt`, `by` — id автора). Лимит — 25 000 записей.
- **Синхронизация:** изменения видны всем открытым вкладкам и устройствам сразу, без перезагрузки. В шапке — индикатор «Сохранено в общей базе».
- **Доступ:** владелец делится ссылкой через меню Share. Уровень Contributor и выше — может добавлять и удалять записи; Viewer — только просмотр (форма скрыта).
- **Удаление и восстановление** подтверждаются прямо на странице (системные окна подтверждения в артефакте не работают). «Восстановить» заменяет всю общую базу и предупреждает об этом.
- **Выгрузка CSV/JSON** — через окно сохранения файла claude.ai.
- **Перенос из версии 1:** в старом `index.html` нажать «Резервная копия», затем в новой версии — «Восстановить» с этим файлом.
- Ограничение: для работы нужен интернет и вход в claude.ai у каждого пользователя.
